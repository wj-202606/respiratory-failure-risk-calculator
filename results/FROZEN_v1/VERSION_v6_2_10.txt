Summary
============================================================
v6.2.10 closes the remaining P0/P1 issues from the pre-submission
audit of v6.2.9. No model was refitted; no prediction probabilities
were changed; no R script, no eICU validation, no APACHE comparison,
and no SOFA comparison were re-run.

Changes:

  [P0] Circular dependency between run_model.py and Figure 2 is
       resolved. Figure 2 is moved out of run_model.py into a
       standalone script fig2_be.py. The pipeline order is now:
         run_model.py -> make_external_stats.py -> fig2_be.py
         -> figS2_hco3.py -> recal_bootstrap.py -> ...
       A clean rebuild no longer requires an existing
       external_auc_stats.csv at the time run_model.py runs.

  [P1] shared_calib.bootstrap_ci_auc_brier is now outcome-stratified,
       matching the sampling scheme declared in ci_config.py and the
       one already used for calibration slope / intercept. Previously
       AUC / Brier used the ordinary bootstrap while slope / intercept
       used the stratified bootstrap. This is now unified.

  [P1] make_external_stats.load_pred() now strictly verifies:
         - hadm_id unique and non-missing
         - mimic_sha256 == EXPECTED_MIMIC_SHA256
         - model_version == v6.2.2
         - landmark == hospital_admission_plus_24h
       A stale or mismatched prediction file can no longer be
       silently accepted.

  [P1] Bootstrap valid-replicate accounting:
         - n_boot_valid is split into four fields:
             n_boot_valid_auc, n_boot_valid_brier,
             n_boot_valid_slope, n_boot_valid_intercept
         - MIN_VALID_BOOT = 1900 is enforced independently for each
           metric; any metric below the threshold aborts the run.
         - Full replicate arrays are written to
             results/external_bootstrap_replicates_<version>.npz
           for audit.

  [P1] fig2_be.py and figS2_hco3.py now verify that the SHA256 of
       the prediction file they read equals the pred_sha256 stored
       in external_auc_stats.csv. Figures cannot be drawn from a
       different prediction file even if the AUC happens to match.

  2. eicu_build_wide.py
  3. eicu_validate.py

  6. run_model.py
  7. figS2_hco3.py                 <-- NEW in v6.2.9
  8. recal_bootstrap.py

 10. make_eicu_supp_tables.py
 11. make_tables.py
 12. check_v6_2_1.py
 13. make_closure_report.py

Steps 1-4 can be skipped when results/ already contains valid
external_validation_coef*.csv, eicu_*.csv, and apache_*.csv.
Steps 5-13 are the minimum required to regenerate Figure 2,
Figure S2, Table 3, Table S6, Table S13, and the closure report.

PowerShell driver: run_pipeline_v6_2_9.ps1
  - Default MimicWideCsv = D:\mimic_wide_with_hco3.csv
  - ExpectedMimicSha256 guard
  - Prints CI_SEED / N_BOOT_CI / CI_METHOD / CI_LEVEL at startup
  - Writes results/pipeline_run_manifest_<timestamp>.txt

If the MIMIC wide file is intentionally replaced:
  1. Update EXPECTED_MIMIC_SHA256 in run_model.py
  2. Update EXPECTED_MIMIC_SHA256 in recal_bootstrap.py
  3. Update ExpectedMimicSha256 in run_pipeline_v6_2_9.ps1
  4. Update this VERSION file
  5. Re-run steps 5-13 and archive the new closure report
Failure to update all four places will cause the guard to abort
with FATAL, which is the intended behavior.

Real MIMIC-IV / eICU-CRD execution: completed on the user's local
environment. Raw patient-level data are not redistributed.
